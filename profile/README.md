# SyntraChat

**Your conversations, with room to breathe.**

An open-source desktop workspace built with Rust, Tauri 2 and TypeScript. Native
WebViews, independent account profiles and explicit security boundaries are the
foundation. No Electron runtime. No SyntraChat analytics or advertising SDKs.

| Repository | Purpose |
| --- | --- |
| [Desktop](https://github.com/SyntraChat/SyntraChat-Desktop-Tauri) | Client, native integrations, compatibility evidence |
| [Installer](https://github.com/SyntraChat/SyntraChat-Installer) | Independent Rust installer and release verification |
| [.github](https://github.com/SyntraChat/.github) | Shared standards and CI workflows |

Status: foundation preview. Voice, authenticated service compatibility, embedded tabs,
media and installation lifecycle require later milestones. Contributions should include
tests and accurate platform limitations. See [contributing](../CONTRIBUTING.md) and
[security reporting](../SECURITY.md).
