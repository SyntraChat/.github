# SyntraChat community

Organization-wide standards for an independent Rust/Tauri multi-messenger.

- [Desktop client](https://github.com/SyntraChat/SyntraChat)
- [Custom Rust installer](https://github.com/SyntraChat/SyntraChat-Installer)
- [Community and reusable workflows](https://github.com/SyntraChat/.github)

The desktop repository was renamed from SyntraChat-Desktop-Tauri to SyntraChat while
preserving its history. Exactly three primary repositories form the project.

Both executables are in early development. A successful build is not a stable-release
certification. Follow explicit milestone evidence and compatibility documentation.
