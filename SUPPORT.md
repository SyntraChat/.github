# Support

Read the desktop compatibility and troubleshooting docs before filing a bug. Include OS,
WebView runtime, app version and non-sensitive reproduction steps. A login screen loading
does not imply messaging, calling, notification or screen-share support. Never attach
browser profile directories, settings containing private URLs, passwords or tokens.

Use the affected repository's issue tracker for ordinary bugs. Use SECURITY.md for
vulnerabilities. Service authentication issues may need the service's own support.
